# Ejercicios de los profes

Aquí se guardan todos los ejercicios que hacemos con los profes (HTML, JavaScript y otros temas).

## Estructura

- `html/` — ejercicios de HTML y CSS
- `javascript/` — ejercicios de JavaScript
- otros temas irán sumando su carpeta

## Cómo subir a GitHub

Después de cada clase se sube lo nuevo automáticamente. Si hay que hacerlo a mano:

```bash
cd ~/ejercicios
git add -A
git commit -m "ejercicios"
git push
```
